    修正模式（類似 Vim） 提案

    組字中按 Esc 進入修正模式（不再直接清除整段；修正模式中再按 Esc 才清除）。手不用離開主鍵區，就能看到每個字背後的注音和按鍵並直接修改。

    標點與符號

    每個符號鍵要全形還是半形。另一種寫法永遠在候選窗按 ↓ 就有。

    符號鍵輸出 已完成

    快速設定
    按鍵全形半形候選窗裡的其他符號
    Ctrl+符號 打全形標點
    微軟新注音／華碩的習慣：Ctrl+, ，、Ctrl+; ；、Ctrl+Shift+/ ？。純英文模式時交給程式。

    符號面板 提案

    常用括號引號希臘字母數學箭頭單位

    按 ` 打開面板（華碩也是這個鍵）。Tab 換分類、1–9 或方向鍵選、連按兩次 ` 輸出 ` 本身。

    希臘字母、數學符號、箭頭、單位（℃、㎡、％）都在這裡，不用記快捷鍵。常用的符號會自動排前面。

    Alt 快速切換？

    不建議用 Alt：Alt+字母是程式選單的快捷鍵，Alt+Shift 是 Windows 切換鍵盤，單按 Alt 會跳到選單列。符號寬度改用上面的設定、候選窗 ↓ 和符號面板處理。

    我的詞庫

    自己加的詞和輸入法學到的詞都在這裡，可以分類、搜尋、刪除。朋友的名字放進「朋友」分類，打注音時會排第一，不用每次找半天。

    新增詞 提案

    也可以在打字時把詞加進來：修正模式按 a，或候選窗按 Ctrl+D。

    按住快速鍵說話，放開就把文字打到游標位置。全部在你的電腦上辨識，聲音不會上傳。

    語音輸入 Phase 6

    快速鍵
    建議按住右 Ctrl：單獨按下不會觸發程式功能。
    辨識模型
    Breeze-ASR-25：聯發科針對台灣華語與中英夾雜調整，用你的 RTX 4070。SenseVoice：沒有顯示卡也很快。

    資料與隱私

    你的設定和學到的詞都存在這台電腦，可以匯出帶到另一台電腦。

    我的記憶 Phase 7

    資料位置
    %APPDATA%\SmartIME（設定、詞庫、學習紀錄、紀錄檔）
    匯出／匯入我的記憶
    換電腦時，在舊電腦匯出一個檔案，到新電腦安裝後匯入，打字習慣和詞庫都會跟過去。
    清除學習紀錄
    只清掉自動學到的，自己加的詞會保留。
