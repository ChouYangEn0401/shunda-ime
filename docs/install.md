# 安裝、移除、搬家

給使用者的完整說明。只想快點裝好的話，[專案首頁](index.html)的三個步驟就夠了。

---

## 需要什麼

| | |
|---|---|
| 作業系統 | Windows 10 或 11，64 位元 |
| 權限 | 安裝時需要系統管理員（註冊輸入法要寫入系統） |
| 網路 | **不需要**。安裝檔是完整的，裝好以後打字也不連網 |
| 其他軟體 | 不用先裝 Python，也不用先裝 PIME |

安裝檔大約 20 MB，裝完約佔 120 MB（大部分是中文詞庫和一份專用的 Python）。

---

## 安裝

1. 到 [Releases](https://github.com/ChouYangEn0401/shunda-ime/releases) 下載
   `ShundaIME-Setup-<版本>.exe`，按兩下執行。

2. **Windows 可能會擋下來。** 安裝檔還沒有數位簽章（那要付費向憑證機構申請），
   所以 SmartScreen 會顯示「Windows 已保護您的電腦」。
   按「**其他資訊**」→「**仍要執行**」。

   不放心的話，Releases 頁面上每一版都附了 SHA-256；下載後用
   `certutil -hashfile ShundaIME-Setup-<版本>.exe SHA256` 核對，
   或是自己從原始碼建一份（見 [CONTRIBUTING.md](../CONTRIBUTING.md)）。

3. 接受系統管理員權限確認，一路下一步。安裝程式會：
   - 把輸入法放到 `C:\Program Files (x86)\PIME\smartime`
   - 註冊成 Windows 的中文輸入法，加進你的語言清單
   - 最後自動打一行字測試一次，確認真的能用

4. 按 <kbd>Win</kbd> + <kbd>Space</kbd> 切換到「**順打輸入法**」。

### 關於 PIME

順打建在 [PIME](https://github.com/EasyIME/PIME) 輸入法框架上。
安裝檔**只帶 PIME 的核心三個檔案**（`PIMELauncher.exe` 和兩個
`PIMETextService.dll`），不會順便裝上新酷音、RIME 等 PIME 官方版附帶的其他輸入法。

如果你電腦上已經有 PIME 官方版，順打會和它共用核心、不會覆蓋它。
這時安裝畫面會多一個選項：「**移除 PIME 官方版附帶的其他輸入法**」，
勾了就只留下順打（預設不勾）。

## 設定

- 開始功能表 →「**順打輸入法 設定**」
- 或系統匣的輸入法圖示按右鍵 →「**設定…**」

設定頁是一個跑在本機的網頁，用 Edge 的應用程式視窗開啟。它不連外網。

值得先看的幾頁：

| 頁面 | 裡面有什麼 |
|------|-----------|
| 一般 | 每種打字方式一張卡片；哪些模式要放進 <kbd>Shift</kbd> 輪流 |
| 打字與選字 | 候選窗的字體大小、幾欄、接續建議要顯示幾個 |
| 標點與符號 | 每個鍵 × 四種按法的完整對照表，每一格都可以改 |
| 我的詞庫 | 「自動收集」（輸入法學到的）和「我的詞庫」（整理過的）兩區 |
| 資料與隱私 | 匯出、匯入、清除學習紀錄、除錯紀錄 |
| 關於 | 版本、檢查更新、授權 |

## 更新

設定頁「關於」→「**檢查更新**」。有新版本時會出現「下載並安裝」，
按下去會下載安裝檔並啟動它（安裝檔自己會跳系統管理員權限確認）。

預設每天自動檢查一次。那是對 GitHub 公開 API 的一個 HTTPS 查詢，
不帶帳號、不帶任何可以認出你的識別碼，也不會自己安裝任何東西。
在同一頁可以關掉；關掉以後輸入法完全不連網。

直接覆蓋安裝新版本也可以，你的設定和詞庫都會留著。

## 移除

Windows 設定 → 應用程式 → 應用程式與功能 → 「順打輸入法」→ 解除安裝。

- PIME 核心：**順打自己裝的才會一起移除**。如果核心本來就是 PIME 官方版裝的，會留著。
- 你的資料（設定、我的詞庫、學習記憶）**不會**被刪掉。要連資料一起清掉，
  移除後手動刪除 `%APPDATA%\SmartIME`。

移除後如果還沒重新開機就想重裝，直接裝即可——安裝程式會處理還在使用中的檔案。

## 換電腦、備份

所有個人資料都在 `%APPDATA%\SmartIME`：

| 檔案 | 內容 |
|------|------|
| `config.json` | 所有設定 |
| `user.db` | 我的詞庫、學習記憶、片語（SQLite） |
| `recent-symbols.json` | 符號面板最近用過的 |
| `update.json` | 上次檢查更新的結果（刪掉也沒差） |
| `logs/` | 除錯紀錄（預設關閉） |

**搬到新電腦**：設定頁 →「資料與隱私」→「匯出」，會得到一個 `.smartime` 檔。
在新電腦上同一頁「匯入」。

匯入是**合併，不是覆蓋**：

- 你自己加的詞和分類會加進去
- 同一個詞的使用次數相加
- 封鎖過的詞維持封鎖
- 新電腦上原本就有的東西都不會消失

所以可以把好幾台電腦的詞庫逐一匯進同一台，不用擔心互相蓋掉。
**同一個檔案不小心匯入兩次也沒關係**：每個匯出檔都有自己的編號，第二次匯入時次數不會再加一次
（但你在這台刪掉的詞還是會補回來）。匯入完會告訴你合併了幾個新的詞、幾則片語、幾個符號。

設定要不要一起匯入是分開的選項，而且**只有這一項是覆蓋**；舊版本的匯出檔沒有的設定項目會保留你現在的值。

## 裝不起來、怪怪的

### 語言清單裡找不到「順打輸入法」

1. 登出再登入一次（Windows 有時候要重新載入語言設定才看得到新的輸入法）。
2. 還是沒有的話，Windows 設定 → 時間與語言 → 語言與地區 → 中文（繁體，台灣）→
   「...」→ 語言選項 → 鍵盤，確認清單裡有它。

### 切過去了，但打字沒反應

輸入法的後端是一個獨立的程式。重新啟動它：

1. 工作管理員裡結束 `PIMELauncher.exe`（它會自己重開），或登出再登入。
2. 還是不行的話，到設定頁「資料與隱私」打開「除錯紀錄」，重現一次，
   然後把 `%APPDATA%\PIME\Log` 裡的紀錄附在
   [Issue](https://github.com/ChouYangEn0401/shunda-ime/issues) 上。

### 提示列／候選窗沒有出現

有些程式（特別是以系統管理員身分執行的）會擋掉外來的視窗。
設定頁「打字與選字」可以把面板關掉，改用 PIME 原本的候選窗。

### 打的字有時候會整段不見

這是編輯器把「還沒送出的組字」丟掉造成的。順打預設會在組字中顯示一個**小藍點**，
看到它就表示這段字還沒真的寫進文件，點別的地方會有風險——先按 <kbd>Enter</kbd> 送出。
（設定頁「打字與選字」的 `composing_indicator` 可以關掉。）

### 某個程式裡 <kbd>Ctrl</kbd> 組合被輸入法吃掉

中文模式下 <kbd>Ctrl</kbd> + 標點鍵是中文標點。
設定頁「標點與符號」裡把那一格**清空**，就把那個組合還給程式。
純英文模式下所有 <kbd>Ctrl</kbd> 組合一律交給程式。

### 回報問題

[Issues](https://github.com/ChouYangEn0401/shunda-ime/issues)。附上這些會快很多：

- 你**按了哪些鍵**（不是打出來的字），例如 `ji3ee/4dj94`
- 預期出現什麼、實際出現什麼
- 哪一個程式裡發生的
- 除錯紀錄（設定頁「資料與隱私」可以打開）
