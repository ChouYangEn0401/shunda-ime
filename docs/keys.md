## 打字

| 動作 | 按鍵 |
|------|------|
| 打中文 | 直接用注音打（大千或倚天），按聲調鍵轉成中文 |
| 打英文 | 直接打，不用切換；未完成的注音會以原字母顯示，旁邊提示注音 |
| 接續詞 | 提示列右邊出現「xx ⇥」時按 <kbd>Tab</kbd>；<kbd>Shift</kbd>+<kbd>Tab</kbd> 列出全部 |
| 加到我的詞庫 | <kbd>Ctrl</kbd>+<kbd>D</kbd>（游標前的中文；候選窗中則加入目前這個候選） |
| 送出 | <kbd>Enter</kbd>，或打句讀標點（，。？！：；）時自動送出前面的句子 |
| 換行 | 符號面板「常用」分頁的 <kbd>⏎</kbd>：送出目前的字再打一個換行。也可以在設定頁「快捷鍵」把 <kbd>Shift</kbd>／<kbd>右 Shift</kbd>／<kbd>Ctrl</kbd>+<kbd>Enter</kbd> 指定成換行（預設關閉） |
| 刪除 | <kbd>Backspace</kbd> 刪掉游標前「看得到的一個字」，連同緊貼著它、被略過的雜鍵 |
| 復原 | 組字中 <kbd>Ctrl</kbd>+<kbd>Z</kbd> / <kbd>Ctrl</kbd>+<kbd>Y</kbd>（一個字／詞算一步） |
| 修改前面的字 | <kbd>←</kbd> <kbd>→</kbd> 把游標移到字前面，提示列顯示它的注音和按鍵，再按 <kbd>↑</kbd>/<kbd>↓</kbd> |
| 其他快捷鍵 | 組字中按 <kbd>Ctrl</kbd>+<kbd>V</kbd>、<kbd>Ctrl</kbd>+<kbd>S</kbd>、F 鍵等：先送出組字，再交給程式 |

### 打字容錯

- **順序打反也認得**：同一個字的注音鍵顛倒照樣出字（`k27` → 的、`8a3` → 碼），提示會顯示正確順序
- **多按的鍵會被略過**：快打時蹭到的單一字母不會變成亂碼（`我e更快` → 我更快），
  提示列會出現紅色的「略過 e ↓」，按 <kbd>↓</kbd> 候選窗最後會多一組紅色的**「略過的鍵」**，選了就把那個鍵留下來；
  修正模式的「按鍵」檢視裡對著它按 <kbd>e</kbd> 也一樣
- **空白是你的分隔記號**：中文後面先打空白再打字母，那個字母就是英文（`第 i 項`、`用 x 表示`）
- **`i␣`、`o␣` 看前後文**：`i am a good guy` 維持英文，`你想我喔`、`喔！好酷！` 變成中文

### 組字中的提示列

| 看到什麼 | 意思 |
|---------|------|
| 一個小藍點 | 這段字還在組字中，**還沒寫進文件**。點別的地方有風險 |
| `ㄊㄧㄢ` | 還沒成字的注音 |
| 紅色的「略過 e ↓」 | 你打的某個鍵被當成手滑，沒有出現在畫面上 |
| 淡藍色的「天氣 ⇥」 | 按 <kbd>Tab</kbd> 就接上這個詞 |
| 「Ctrl+ 2 天下　3 天天」 | 其他接續詞。**按 <kbd>Ctrl</kbd>+<kbd>2</kbd> 就接上「天下」**（組字中單按數字是注音，所以要加 <kbd>Ctrl</kbd>）。同樣的編號在 <kbd>Shift</kbd>+<kbd>Tab</kbd> 清單裡也通用 |
| `⇧⇥ 更多` | <kbd>Shift</kbd>+<kbd>Tab</kbd> 列出全部（最多 18 個） |

## 選字

<kbd>↓</kbd> 或 <kbd>↑</kbd> 叫出候選窗。

| 按鍵 | 作用 |
|------|------|
| <kbd>1</kbd>–<kbd>9</kbd> | 直接選（上排或右邊數字鍵盤都可以，NumLock 開不開都行） |
| <kbd>↑</kbd> <kbd>↓</kbd> | 上下移動，走到底會自動翻到下一頁 |
| <kbd>→</kbd> | **把下一頁開在旁邊變成一欄**，游標留在同一列；再按就一直往右長（最多 4 欄） |
| <kbd>←</kbd> | 往回走一欄；在第一欄再按一次就**收回成一列** |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | 在上面那排**分類籤**之間移動（只看我的詞庫、只看學過…） |
| <kbd>PageUp</kbd> <kbd>PageDown</kbd> | 翻頁 |
| <kbd>Enter</kbd> | 選目前這個 |
| <kbd>Delete</kbd> | 忘記這個學過的詞 |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | 把這個候選加進我的詞庫 |
| <kbd>Esc</kbd> | 取消 |

候選依序分組：**我的詞庫 → 學過 → 詞庫 → 其他讀法 → 原始按鍵**（綠色＝自己的詞）。
候選會跨類別：英文 `mvp` 可以換成「勳」、`i␣`（喔）可以換回英文 `i`、
任何中文都可以換回「原始按鍵」。

## 修正模式（Vim 式）

組字中按 <kbd>Esc</kbd> 進入。字不會送出，按鍵變成指令。
旁邊出現**琥珀色外框的解碼面板**，三列對齊顯示「按鍵 → 注音 → 國字」：

- 被當雜鍵略過的鍵以**紅色刪除線**標出
- 順序打反而被修正的音節以**琥珀色 ↺** 標出
- 自己選過的字有**藍色底線**，我的詞庫／學過的字有**綠點**

只有明確的指令才會離開（<kbd>i</kbd> / <kbd>Esc</kbd> / <kbd>Enter</kbd> / <kbd>D</kbd><kbd>D</kbd>），
其他鍵不會不小心打出字。

| 鍵 | 作用 | 鍵 | 作用 |
|----|------|----|------|
| <kbd>h</kbd> <kbd>l</kbd> | 左右移動 | <kbd>j</kbd> <kbd>k</kbd> | 換成下一個／上一個候選 |
| <kbd>v</kbd> | 游標走：國字 → 注音 → 按鍵 | <kbd>x</kbd> | 刪除（按鍵檢視中刪一鍵） |
| <kbd>e</kbd> | 中文／英文／原始按鍵之間切換；**停在被略過的鍵上按它＝「我就是要這個鍵」** | <kbd>r</kbd> | 重打這個字（打完自動回來） |
| **聲調鍵**（<kbd>空白</kbd> <kbd>6</kbd> <kbd>3</kbd> <kbd>4</kbd> <kbd>7</kbd>） | **改這個字的聲調**：檢（ㄐㄧㄢˇ）按 <kbd>4</kbd> 變 ㄐㄧㄢˋ，再用 <kbd>j</kbd> 走到「鍵」 | <kbd>D</kbd><kbd>D</kbd> | 清除整段（按一次後標頭會變紅確認） |
| <kbd>R</kbd> | **重新判定**：清掉這一段自己選過的記號讓解碼器重算，連按往右多納入一個字 | <kbd>a</kbd> | 加到我的詞庫 |
| <kbd>u</kbd> | 復原（和 <kbd>Ctrl</kbd>+<kbd>Z</kbd> 同一份紀錄） | <kbd>i</kbd> / <kbd>Esc</kbd> | 回到打字（字都還在） |
| <kbd>Enter</kbd> | 送出 | | |

### 打錯注音怎麼辦

| 錯在哪 | 怎麼修 |
|--------|--------|
| 聲調打錯（檢位 → 鍵位、科能 → 可能） | 游標移到那個字，**直接按正確的聲調鍵**，再用 <kbd>j</kbd> <kbd>k</kbd> 走到要的字 |
| 整個音打錯 | <kbd>r</kbd> 重打這個字，打完自動回到修正模式 |
| 多打／少打一個鍵 | <kbd>v</kbd> <kbd>v</kbd> 切到「按鍵」檢視，<kbd>x</kbd> 刪掉多的；少的用 <kbd>r</kbd> 重打 |
| 按錯鍵（想打 `>` 結果打成 `.`） | <kbd>e</kbd> 換回原始按鍵看清楚，再 <kbd>r</kbd> 重打 |
| 自己選過的字把旁邊的鍵卡住了 | <kbd>R</kbd> 重新判定 |

### 什麼時候用 <kbd>R</kbd>

自己一個一個改字的時候，每個選擇都會被釘住。釘太多的時候，
某個鍵可能會被卡在它不屬於的地方——例如「至關」會變成「至 e 灣」，
因為 `e` 被單獨釘成英文了。這時 <kbd>R</kbd> 把那一段的釘子清掉重算，
`ej0␣` 就會重新變回「關」。

面板也可以設定成打字時一直顯示（設定頁「打字與選字」→ 解碼面板 → 「一直顯示」）。

## 標點

每個符號鍵有四種按法，**同一個鍵的四種按法不會打出一樣的字**（預設「鍵帽上的符號」風格）：

| 按法 | 打出 | 例子 |
|------|------|------|
| 單按、<kbd>Shift</kbd> | 鍵帽上印的符號（半形） | <kbd>Shift</kbd>+<kbd>,</kbd> → `<`、<kbd>[</kbd> → `[` |
| <kbd>Ctrl</kbd> | 中文標點 | <kbd>Ctrl</kbd>+<kbd>,</kbd> ，　<kbd>Ctrl</kbd>+<kbd>.</kbd> 。　<kbd>Ctrl</kbd>+<kbd>;</kbd> ；　<kbd>Ctrl</kbd>+<kbd>'</kbd> 、　<kbd>Ctrl</kbd>+<kbd>/</kbd> …　<kbd>Ctrl</kbd>+<kbd>-</kbd> —　<kbd>Ctrl</kbd>+<kbd>[</kbd> <kbd>]</kbd> 「」 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd> | 上排符號的全形 | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>/</kbd> ？　<kbd>+1</kbd> ！　<kbd>+;</kbd> ：　<kbd>+,</kbd> <kbd>+.</kbd> 《》　<kbd>+9</kbd> <kbd>+0</kbd> （）　<kbd>+[</kbd> <kbd>+]</kbd> 『』 |

- 設定頁「標點與符號」有完整對照表（每個鍵 × 四種按法），
  <kbd>Ctrl</kbd> 和 <kbd>Ctrl</kbd>+<kbd>Shift</kbd> 每一格都能改；
  **清空就把那個組合還給程式**
- 也可以改回「微軟相容」（<kbd>Shift</kbd>+<kbd>,</kbd> 也打 ，）或逐鍵自訂全形／半形
- <kbd>Ctrl</kbd> 組合只在中英自動與純中文模式有效；純英文模式照常交給程式
- <kbd>Ctrl</kbd>+<kbd>\\</kbd>、<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>`</kbd> 刻意不用（VS Code 的分割編輯器、新終端機）
- **打錯寬度時**：游標停在標點後按 <kbd>↓</kbd>，全形、半形與相關符號都在候選裡。
  句讀標點（，。？！：；）會把前面的句子送出，但標點本身留在組字區，所以照樣改得動

## 模式

| 模式 | 圖示 | 說明 |
|------|------|------|
| 中英自動（預設） | 自 | 不用切換，依整句判斷每段是中文還是英文 |
| 純注音 | 中 | 每個鍵都是注音（傳統注音輸入法的行為）；數字請用數字鍵盤 |
| 純英文 | 英 | 按鍵直接交給應用程式 |
| 純拼音 | 拼 | 漢語拼音（預設不在 Shift 輪流裡，設定頁勾選） |
| 純倉頡 | 倉 | 倉頡五代（預設不在 Shift 輪流裡，設定頁勾選） |

單按右 <kbd>Shift</kbd> 在**設定頁勾起來的模式**之間輪流。
只勾一個模式的話按了不會有事——要切換記得至少勾兩個。
系統匣圖示按右鍵可以直接選任何模式。

### 拼音與倉頡

中英自動一次混用一種中文（同一個字母在注音、拼音、倉頡意思不同）；
在設定頁「中英自動混用的中文」選。三種打法共用同一份詞庫與學習記憶。

- **拼音**：連著打，不用打聲調（`women` → 我們）；要指定聲調時在音節後打 `1`–`5`（`ma3` → 馬）；
  ü 打 `v`（`lv` → 綠）；`'` 分開音節（`xi'an`）。中英自動時可以直接混打：
  `women de deadline shi mingtian` → 我們的 deadline 是明天
- **倉頡五代**：打碼後按空白出字（`hqi` ␣ → 我），連打的字會用詞頻挑重碼字；
  還沒按空白時，提示列顯示字根與會出的字（竹手戈 → 我）

## 面板與片語

| 要什麼 | 怎麼叫 |
|--------|--------|
| 符號面板 | **連打兩個冒號 `::`**（<kbd>Shift</kbd>+<kbd>;</kbd> 兩下），或單按一下右 <kbd>Ctrl</kbd> |
| 片語（罐頭訊息） | 打 `;;`，可接關鍵字（`;;addr`） |
| 顏文字 | 符號面板裡 <kbd>Shift</kbd>+<kbd>Tab</kbd> 一下就到 |
| 搜尋符號 | **連打三個冒號 `:::`**，或面板開著時再按一下 <kbd>:</kbd> |
| 我的符號 | 符號面板的「我的符號」分頁（內容在設定頁「片語與顏文字」貼上） |

- 符號面板有三種版面，各做各的事：
  - **格子**（常用、括號引號、希臘字母、數學、箭頭、單位、圖形、序號、注音）：
    一次攤開一整張表。方向鍵上下左右各走各的軸、到邊就停，<kbd>1</kbd>–<kbd>9</kbd> 選選取所在那一列
  - **清單**（片語、顏文字、我的符號）：和選字窗一樣，<kbd>→</kbd> 把下一頁開成旁邊一欄，
    一次看到更多；<kbd>←</kbd> 收回
  - **搜尋**（搜尋符號）：打字就篩選，<kbd>Backspace</kbd> 修改關鍵字
- <kbd>Tab</kbd> 換分頁、<kbd>Shift</kbd>+<kbd>Tab</kbd> 反過來換。十三個分頁的視窗大小一樣，換分頁不會跳動
- 片語選中時面板先預覽全文，<kbd>Enter</kbd> 打出；在設定頁「片語與顏文字」管理
- 常用分頁最後有一個 <kbd>⏎</kbd>：選了就送出目前的字再打一個換行
  （給 <kbd>Shift</kbd>+<kbd>Enter</kbd> 傳不過去的遠端桌面用）
- 文字觸發（`::`、`;;`、`:::`）**不會在英文詞中間發動**，所以 C++ 的 `std::vector` 照常打得出來

### 搜尋符號、我的符號

打 `:::` 直接進搜尋，接著打英文或中文關鍵字（`star`、`heart`、`星座`……）就會篩選。
內建約 90 個符號，分星星、愛心、勾叉、天氣、星座、音樂、警示、宗教文化、花色、
手勢、簡單表情、裝飾幾類——刻意只收**黑白符號**，不是彩色 emoji
（這個輸入法的畫面是用 Windows 內建的繪圖介面畫的，彩色 emoji 需要額外的彩色字型
支援，目前還沒做）。

想用自己收藏的顏文字或符號：到設定頁「片語與顏文字」→「我的符號」貼上，
**一行一個**（有些顏文字本身帶空白，例如 `( ͡° ͜ʖ ͡°)`，所以不能用空白切）。
打字時從符號面板的「我的符號」分頁選，最近用過的排最前面；選字框裡對著它按
<kbd>Delete</kbd> 就能刪，不用特地開設定頁。

## 語音輸入

按住右 <kbd>Ctrl</kbd> 說話，放開就打出來。要先到設定頁「語音輸入」安裝元件並下載模型。

- 全部在這台電腦上辨識，**聲音不會上傳**；只有按住右 <kbd>Ctrl</kbd> 時麥克風才會開啟
- 右 <kbd>Ctrl</kbd> 和其他鍵一起按（例如 <kbd>右Ctrl</kbd>+<kbd>C</kbd>）是一般快捷鍵，不會錄音
- 我的詞庫裡自己加的詞（朋友名字、專案術語）會提示辨識器
- 模型：有 NVIDIA 顯示卡選 **Breeze-ASR-25**（3.1 GB，台灣華語與中英夾雜最準），
  沒有就選 **SenseVoice**（170 MB，CPU 也很快）
