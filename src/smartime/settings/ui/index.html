一般

每一種打字方式自成一張卡片：右邊的開關決定它在不在 Shift 的輪流裡，點卡片展開它自己的細部設定。用不到的關掉就好，裡面的設定不用管。

混用哪一種中文
一次混用一種中文：同一個字母在注音、拼音、倉頡的意思都不同，一起猜會互相干擾。三種打法學到的詞是共用的。
單一字母依前後文判斷
i am a good guy 維持英文；你想我i␣ 變成「你想我喔」。關閉後單一字母一律當英文。

中文後面先打空白再打字母，會當成英文（第 i 項）：空白就是你的分隔記號。注音的鍵盤、容錯設定在下面「注音」卡片，混用注音時一樣適用。

注音鍵盤 許氏之後支援
大部分人用大千（Windows 預設）。換鍵盤後下一個按鍵生效。

藍色是聲調鍵。

注音順序容錯
同一個字的注音順序打反也認得：k27→的、8a3→碼、ij3→我。解碼面板以琥珀色 ↺ 標出。
略過多按的雜鍵
我e更快→我更快。被略過的鍵在解碼面板以紅色刪除線標出，也可從候選窗「原始按鍵」找回。保守：只略過很明顯多按的鍵。
注音提示
還沒打聲調時，旁邊顯示會變成的注音（打 k2 顯示 ㄉㄜ）。

連著打，不用打聲調（women → 我們）；要指定聲調時在音節後打 1–5（ma3 → 馬，5 是輕聲）。ü 打 v（lv → 綠），' 分開音節（xi'an），空白結束一個詞。

, . ; 在拼音裡是全形標點（，。；），不是字母。

打碼後按空白出字；連打幾個字時會用詞頻挑重碼字（hqi␣oan␣ → 我們）。還沒按空白時，提示框顯示字根和會出的字。字根對照：

純英文模式不組字，所有按鍵（含 Ctrl+符號）都直接交給程式。只是偶爾打一個英文詞的話，不必切換：中英自動會自己判斷，或打 Caps Lock 直接打大寫。

Shift 輪流

Shift 的切換方式
三段（預設）：上面開著的模式依序輪流。兩段：英文 ⇄ 上次用的中文模式，切英文只要按一下。用左邊還是右邊的 Shift，在「快捷鍵」頁設定。

    順打面板

    候選窗由輸入法自己畫：綠色是你自己的詞（我的詞庫、學過），一組一組排好；Tab 只看某一組。黃色提示框還是會在，面板貼在它下面。

    用順打面板顯示候選
    關閉後改回 PIME 的純文字候選窗（不分組、沒有顏色）。沒在打字時叫出的符號面板一律用 PIME 的。
    候選窗多欄
    開啟後 → 在右邊打開下一欄（一次看更多候選），在第一欄按 ← 收起來；關閉時 ←→ 是翻頁。
    面板顏色
    跟隨 Windows 的淺色／深色模式，或固定一種。

    實驗功能 實驗

    還在試的功能，預設關閉。覺得不好用就關掉，不影響其他功能。

    超智慧推薦
    打字時多一個紫色面板：「接下來」用詞庫接出比較長的一串（例：電腦 → 斷層掃描器），「也許是」列出和剛打的字同音、但比較常見的詞（打鬥號 → 逗號）。一直顯示到送出為止，Shift+Tab 按數字選。只靠詞頻、沒有語意，長句有時會接得很怪。
    瘋狂模式（注音）
    每個字只打注音的開頭（聲母或前一兩個符號、不打聲調），一路打下去自動猜成詞：ja（ㄨㄇ）→ 我們、rwu → 今天。開啟時解碼面板一直顯示，琥珀色「…」是猜出來的音節；猜錯照樣用 ↓ 或修正模式改。打完整的注音也照常可以。

    候選窗與送出

    每頁候選數
    候選字大小
    下次切換到輸入法時生效。
    句讀標點自動送出
    打 ，。？！：； 時把整段送出。關掉後要按 Enter 才送出，但可以在這些標點上按 ↓ 換成半形或其他符號。
    組字區最多幾個字
    超過時自動送出前面的字（正在打的音節不會被打斷）。

    智慧修正

    打快時的錯誤會自動修好；修不好的，用候選窗或修正模式手動改，改過的會記成詞。

    注音順序容錯、略過多按的雜鍵、單一字母判斷，是各打字方式自己的設定，搬到「一般」裡對應的卡片（注音、中英自動）。

    學習

    記住我選的字
    從候選窗選過的詞、接受過的接續、英文↔中文的選擇，下次排前面。只從你明確的選擇學習。學錯的：按 ↓ 打開選字框、移到那個詞上按 Delete，或在「我的詞庫」刪除。
    學到新詞時提示
    第一次記住某個詞時，在提示框顯示「記住了「…」」，讓你知道學了什麼、怎麼忘掉。選字框裡學過的詞旁邊會標「學過」，自己加的詞標分類。

    修正模式（類似 Vim） 即將推出

    組字中按 Esc 進入修正模式：旁邊出現琥珀色外框的解碼面板，三列對齊顯示「按鍵 → 注音 → 國字」，被略過的雜鍵、順序被修正的音節都看得到。手不用離開主鍵區就能直接修改；只有 i／Esc／Enter／DD 這些明確的指令才會離開。

    紅色刪除線＝被當成雜鍵略過的鍵；琥珀色 ↺＝順序打反、已照正確順序讀；藍色底線＝你自己選的字；綠點＝我的詞庫／學過。

    標點與符號

    鍵盤上每個符號鍵，單按、Shift、Ctrl、Ctrl+Shift 各打出什麼，都在下面這張表。看得到的符號都打得出來，同一個鍵的四種按法不會重複。

    符號鍵的四種按法

    風格
    鍵單按ShiftCtrlCtrl+Shift
    • Ctrl、Ctrl+Shift 兩欄可以直接改（每格一個字）；清空＝這個組合交給程式（例如 VS Code 的 Ctrl+\ 分割編輯器），↺ 恢復預設。只在中文模式有效，純英文模式的 Ctrl 組合鍵一律交給程式。
    • 黃底＝同一個鍵有兩種按法打出一樣的字（可以改掉，多放一種符號）。
    • 打錯寬度時，游標停在標點後按 ↓，全形、半形和相關符號都在選字框裡（表中「↓ ，」）。例外：，。？！：； 預設會立刻把整段送出，之後就不能再按 ↓ 換——可到「打字與選字」關掉「句讀標點自動送出」。
    Ctrl+符號 打中文標點
    關掉後 Ctrl 欄全部交給程式。純英文模式時本來就交給程式。

    符號面板 即將推出

    常用括號引號希臘字母數學箭頭單位

    單按一下右邊的 Ctrl 打開面板，再按一次關閉（按住右 Ctrl 仍是語音輸入；` 保留給你框程式碼）。Tab 換分類、Shift+Tab 上一類、1–9 或方向鍵選。沒在打字時選的符號會直接打出來。

    希臘字母、數學符號、箭頭、單位（℃、㎡、％）都在這裡，不用記快捷鍵。常用的符號會自動排前面。

    打開符號面板的鍵
    只有「單獨按一下」才算：右 Ctrl 和其他鍵一起按（右 Ctrl+C）是一般快捷鍵，按住超過 0.35 秒是語音輸入。右 Alt 在部分程式會順便打開選單列，所以預設改用右 Ctrl。

    為什麼不是 Ctrl+Alt+符號？

    Windows 不會把「按住 Alt 時按的鍵」交給輸入法，所以 Ctrl+Alt+, 這類組合在這個輸入法收不到。Alt、Ctrl 單獨按一下則收得到，因此用「單按右 Ctrl」（或右 Alt）開符號面板。全形／半形用上面的設定或候選窗 ↓ 切換。

    我的詞庫

    輸入法自動收集的詞，和你自己整理的詞，分成兩區。自動收集的詞給它一個分類，就成為「我的詞庫」的一員；朋友的名字放進「朋友」分類，打注音時排第一，不用每次找半天。

    新增詞

    也可以在打字時加詞：打好、修好後按 Ctrl+D 把游標前的中文加入詞庫；在候選窗按 Ctrl+D 加入選中的詞。英文詞（例如 vscode）直接輸入即可。

    詞條

    分類

    候選窗會在詞旁標上分類，例如「陳怡君　朋友」。刪除分類不會刪除裡面的詞。

    片語與顏文字

    常用的一段話——罐頭訊息、地址、簽名、同一類業務的回覆——存在這裡。打字時打 ;;（可以接著打關鍵字篩選），選中時先在面板預覽全文，按 Enter 才打出來。也可以單按右 Ctrl 打開符號面板，在「片語」分頁選。

    新增片語

    關鍵字用英文字母最快：打 ;;addr 就只剩下關鍵字是 addr 開頭的片語。沒有關鍵字也可以，從清單選。

    我的片語

    叫出方式

    打字時打 ;; 叫出片語
    ;; 不是任何注音，英文裡也幾乎不會出現。按 Esc 關掉清單時會保留打的字，真的要打 ;; 也可以。拼音、倉頡模式的 ; 是全形標點，請用符號面板的「片語」分頁。

    顏文字

    單按右 Ctrl 打開符號面板，Shift+Tab 就到「顏文字」分頁：依心情分組（開心、喜歡、難過、生氣、驚訝、無奈、害羞、打招呼、謝謝抱歉、加油、睡覺、動物……），最近用過的排在最前面。

    我的符號

    網路上收藏的顏文字、特殊符號，貼在這裡就能在打字時用—— 打 ::: 開啟符號面板後 Tab 到「我的符號」分頁選， 最近用過的排最前面。

    一行一個——有些顏文字本身就帶空白，用空白分隔會拆散它。重複貼上的會自動略過。

    更多符號

    下載更大的符號庫
    額外收錄約 1300 多個符號（技術、數學、箭頭、圖形、圈號……），來自 Unicode 官方字元資料庫。不內建在安裝檔裡——下載一次（約 150 KB），存在你的電腦上。

    在 emoji 分頁裡使用
    下載完成後才能打開；關閉時「emoji」分頁只用內建的常用符號。

    快捷鍵

    可以調整的按鍵放在最上面；下面是打字時能用的所有按鍵。

    可以調整的按鍵

    切換模式的 Shift
    單按一下哪一邊的 Shift 切換模式（像 Windows 注音可以選左右）。按住 Shift 打大寫不受影響。要輪流哪些模式在「一般」選。
    符號面板：打 ::
    連打兩個冒號（Shift+; 兩下）就打開， 不需要任何熱鍵。Tab 換到括號、希臘字母、數學、箭頭、單位、片語、顏文字…… 不會在英文詞中間發動，所以 C++ 的 std::vector 照常打得出來。
    符號面板：單按右 Ctrl
    單按一下就打開（再按一次關閉）；按住右 Ctrl 是語音輸入。 （以前可以選右 Alt，已經移除：Windows 不會把按著 Alt 的鍵送給輸入法，選了等於沒有熱鍵。）
    修正模式
    組字中按 Esc 進入、再按一次回到打字。關閉後 Esc 直接清除整段。
    片語
    打 ;; 叫出片語清單。
    送出並換行的 Enter
    組字中按它會先送出文字，再把這個鍵交給程式換行。 預設關閉：Shift+Enter 在大部分編輯器裡本來就有自己的意思，交出去會改變它們的行為。 不管選哪個，符號面板「常用」分頁的 ⏎ 都可以換行。
    Ctrl+符號打中文標點
    每個鍵打什麼、要不要交給程式，在「標點與符號」逐格調整。

    語音輸入

    按住右 Ctrl 說話，放開就把文字打到游標位置，任何程式都可以用。全部在你的電腦上辨識，聲音不會上傳；只有按住時麥克風才會開啟。

    記憶大小

    同一個詞選再多次也只占一筆（只增加次數），所以檔案隨「不同的詞」成長，一萬個詞約 1–2 MB。只用過一次、超過 4 個月沒再用的學習紀錄會自動清掉；自己加的詞和封鎖的詞不會。

    匯入我的記憶
    選另一台電腦匯出的檔案。永遠是合併，不會蓋掉你現有的東西：沒有的詞、片語、符號、分類會加進來，兩邊都有的詞把用過的次數相加，自己加的詞和封鎖的詞優先保留。
              多台電腦的檔案可以一個一個匯入，最後合在一起；同一個檔案重複匯入也不會把次數灌水。
