每種打字方式一張卡片：開關決定它在不在 Shift 的輪流裡，「開啟時」選一開始用哪一種，點卡片看它的設定。

混用哪一種中文
中英自動一次只混一種中文。三種打法學到的詞共用。
單一字母依前後文判斷
i am a good guy 維持英文；你想我i␣ 變成「你想我喔」。關閉後單一字母一律當英文。
英文打錯自動更正
英文字打完時自動改小錯（teh→the、wrold→world）；真的字、專有名詞、你自己的詞不動。改過的字標琥珀色 ↺，按 ↓ 選「原樣」改回來，之後不再改它。

中文後面先打空白再打字母，會當成英文（第 i 項）。注音鍵盤和容錯在下面「注音」卡片設定。

注音鍵盤 許氏之後支援
大部分人用大千（Windows 預設）。換鍵盤後下一個按鍵生效。

藍色是聲調鍵。

注音打錯容錯
打快的常見錯也認得：順序打反（k27→的）、聲調打早（248→大）、漏打聲調（clm/4→好用）、漏打一聲的空白（rupwu0→今天）。修過的地方標琥珀色 ↺。
略過多按的雜鍵
多按的鍵自動略過（我e更快→我更快），提示列用紅色標出；按 ↓ 選紅色的「略過的鍵」放回來。保守：只略過很明顯的。連打三個以上同一個字母一律照打。
注音提示
還沒打聲調時，旁邊顯示會變成的注音（打 k2 顯示 ㄉㄜ）。

連著打，不用打聲調（women → 我們）；要指定聲調時在音節後打 1–5（ma3 → 馬，5 是輕聲）。ü 打 v（lv → 綠），' 分開音節（xi'an），空白結束一個詞。

, . ; 在拼音裡是全形標點（，。；），不是字母。

打碼後按空白出字；連打幾個字時會用詞頻挑重碼字（hqi␣oan␣ → 我們）。還沒按空白時，提示框顯示字根和會出的字。字根對照：

    候選窗

    綠色是你自己的詞（我的詞庫、學過）；Tab 只看某一組；紅色「略過的鍵」選了就把那個鍵留下來。

    現在在第幾頁
    右上角寫著「第 3／27 頁」，不在第 1 頁時藍底。候選窗打開時停在目前的字，可能在後面幾頁；按 Home 回第 1 頁（最常用的詞）。
    把國字換成注音
    候選窗最後一組「注音」：這個字（天 → ㄊㄧㄢ）或整段（你好 → ㄋㄧˇㄏㄠˇ），選了就換成注音。 修正模式裡游標停在字上按 z，那個字就換成注音，再按一次換回國字。
    用順打面板顯示候選
    關閉後改用純文字的候選窗（不分組、沒有顏色），沒在打字時的符號面板也一樣。
    候選窗多欄
    → 在右邊多開一欄，← 收回；關閉時 ←→ 是翻頁。
    每頁候選數
    一欄列出幾個候選。
    候選字大小
    下次切換到輸入法時生效。
    面板顏色
    跟隨 Windows 的淺色／深色模式，或固定一種。

    送出

    句讀標點自動送出
    打 ，。？！：； 時把整段送出。關掉後要按 Enter 才送出，但可以在這些標點上按 ↓ 換成半形或其他符號。
    組字區最多幾個字
    超過時自動送出前面的字（正在打的音節不會被打斷）。

    組字中要「送出並換行」的 Enter，在「快捷鍵」設定。

    實驗功能 實驗

    還在試的功能，預設關閉。覺得不好用就關掉，不影響其他功能。

    超智慧推薦
    打字時多一個紫色面板：「接下來」接出比較長的一串（電腦 → 斷層掃描器），「也許是」列出同音但更常見的詞（鬥號 → 逗號）；按 Shift+Tab 再按數字選。只靠詞頻，長句有時接得很怪。
    瘋狂模式（注音）
    每個字只打注音的開頭、不打聲調，自動猜成詞：ja → 我們、rwu → 今天。開著時解碼面板一直顯示；猜錯照樣用 ↓ 或修正模式改，完整的注音也照常能打。

    智慧修正

    打快時的錯誤會自動修好；修不好的，用候選窗或修正模式手動改，改過的會記成詞。

    自動修正的開關跟著打字方式走，在「一般」的卡片裡：「注音」有注音打錯容錯、略過多按的雜鍵；「中英自動」有單一字母判斷、英文打錯自動更正。

    修正模式（類似 Vim） 即將推出

    使用修正模式
    組字中按 Esc 進入，再按一次回到打字。關閉後 Esc 直接清除整段。
    解碼面板（按鍵／注音／國字）
    顯示每個鍵被當成什麼，不會改變打出來的字。預設只在修正模式顯示；瘋狂模式開著時固定一直顯示。

    修正模式的解碼面板三列對齊：按鍵 → 注音 → 國字。常用的鍵寫在面板下方；只有 Esc／Enter／DD 會離開修正模式。

    紅色刪除線＝被當成雜鍵略過的鍵；琥珀色 ↺＝順序打反、已照正確順序讀；藍色底線＝你自己選的字；綠點＝我的詞庫／學過。

    按鍵動作
    ← →（或 h l）移到上一格／下一格：一個中文字，或一整個英文字、數字
    ↓選字窗：這個字、從這裡開始的詞、重新分組
    j k只換游標上的這個字（同音的下一個／上一個，不開視窗；旁邊的字不動）
    v切換顯示：國字 → 注音 → 按鍵
    x刪掉游標上的那一格；在「按鍵」檢視時只刪一個鍵（例如那個多按的 e）
    e這段在 中文 ⇄ 英文 ⇄ 原始按鍵 之間切換
    z游標上的國字換成注音（你 → ㄋㄧˇ），再按一次換回國字
    r重打這一個字（其他字不動，打完自動回到修正模式）
    a把游標前的詞加入詞庫
    u復原上一步（和打字時的 Ctrl+Z 同一份紀錄；Ctrl+Y 重做）
    Esc（或 i）回到打字（字都還在）；Enter 送出整段
    D D清除整段（要連按兩次，不會送出）

    學習

    記住我選的字
    選過的詞、接受過的接續、中英的選擇，下次排前面；只學你明確選的。改錯一個字時，記的是它和前後文組成的詞。學錯了：按 ↓ 打開選字框，在那個詞上按 Delete，或到「我的詞庫」刪除。
    學到新詞時提示
    第一次記住某個詞時，提示列顯示「記住了「…」」。
    刪掉重打時換一個
    用 Backspace 刪掉剛打的字、一分鐘內再打一樣的鍵，就自動換成同音的下一個（每一洲 → 每一周 → 每一週），提示列會說換了什麼。Ctrl+Z 換回，↓ 看全部。

    修正紀錄

    你改過的字。同一個修正做到第 2 次，改成的詞會自動加進「我的詞庫」的「程式推薦」分類（標 ✓），排在同音詞前面；不要就到「我的詞庫」刪掉。

    原本改成怎麼改的次數最近

    只清掉這張表，不動已經學到的詞。

    標點與符號

    鍵盤上每個符號鍵，單按、Shift、Ctrl、Ctrl+Shift 各打出什麼，都在下面這張表。鍵盤上沒有的符號（希臘字母、數學、箭頭、emoji……）從符號面板選。

    前三頁最常用：常用標點、錄音暫存（剛剛語音說的話）、快速詞。

    我的詞庫

    自動收集的詞和你自己整理的詞分兩區。給自動收集的詞一個分類，它就進「我的詞庫」，打字時排最前面——例如把朋友的名字放進「朋友」。

    新增詞

    打字時也能加：Ctrl+D 把游標前的中文或英文字（候選窗開著時是選中的詞）加入詞庫。英文照你打的加進「常用英文」，以後不再被改（venv、wrold）。清單裡的詞按「編輯」可以改字或注音。

    詞條

    整理建議

    可能用不到的詞，勾選後刪除。只看自動收集的詞，你加的、分了類的不會出現。

    詞讀音為什麼最近

    分類

    候選窗會在詞旁標上分類，例如「陳怡君　朋友」。刪除分類不會刪除裡面的詞。

    片語與顏文字

    常用的一段話（地址、簽名、罐頭回覆）存在這裡。打 ;; 叫出來，可以接著打關鍵字篩選；先預覽，按 Enter 才打出。顏文字和你收藏的符號也在這一頁。

    新增片語

    關鍵字用英文字母最快：打 ;;addr 只列出 addr 開頭的片語；沒有關鍵字就從清單選。分類只在這一頁整理用，不影響打字。

    我的片語

    關鍵字片語分類用過

    快速詞

    打到觸發字，提示列最前面會用橘色建議這段文字，按 Tab 直接打出（取代觸發字）。可以自己寫，也可以直接連到一筆片語。

    還沒有快速詞。例：觸發字 art → artifact。

    顏文字

    單按 右 Ctrl（或打 ::）打開符號面板，按 Tab 換到「顏文字」分頁：依心情分組，最近用過的排最前面。

    我的符號

    網路上收藏的顏文字、特殊符號，貼在這裡就能在打字時用：打開符號面板，在「我的符號」分頁選，最近用過的排最前面。

    一行一個——有些顏文字本身就帶空白，用空白分隔會拆散它。重複貼上的會自動略過。

    片語的 ;;、打開符號面板的鍵要換或關掉，都在「快捷鍵」。更大的符號庫在「標點與符號」下載。

    快捷鍵

    會用到的鍵都在這一頁：上面是可以換、可以關的，下面是打字時所有按鍵的對照表。

    可以調整的按鍵

    切換模式的 Shift
    單按一下哪一邊的 Shift 切換模式（像 Windows 注音可以選左右）。按住 Shift 打大寫不受影響。要輪流哪些模式在「一般」選。
    送出並換行的 Enter
    組字中按它：先送出文字，再讓程式換行。預設關閉，因為 Shift+Enter 在很多程式裡另有用途。符號面板「常用標點」分頁的 ⏎ 隨時可以換行。
    片語：打 ;;
    叫出片語清單，可以接著打關鍵字篩選；按 Esc 關掉清單會保留打的字。拼音、倉頡模式改從符號面板的「片語」分頁選。
    符號面板：打 ::
    連打兩個冒號（Shift+; 兩下）就打開；英文詞中間不會發動（std::vector 照常打）。
    符號面板：單按一下
    單按一下就打開，再按一次關閉。只有「單獨按一下」才算：和其他鍵一起按（Ctrl+C）、或按著點滑鼠，是一般快捷鍵。 沒有右 Ctrl 的筆電選左 Ctrl。
    語音輸入：按住
    按住說話、放開就打出來（要先在「語音輸入」開啟）。和其他鍵一起按不會錄音；左 Ctrl 按著點滑鼠、轉滾輪也不會。可以和符號面板同一個鍵：短按開面板，按住才是語音。

    只能選 Ctrl：Alt、Shift、Caps Lock、F1–F12 在 Windows 或程式裡都另有用途，只有單按 Ctrl 不會觸發別的功能。

    其他和按鍵有關的開關在各自的頁面：Esc 進入修正模式在「智慧修正」；Ctrl+符號打什麼標點在「標點與符號」。

    情境按鍵動作狀態

    語音輸入

    按住 右 Ctrl 說話，放開就把文字打到游標位置，任何程式都可以用。全部在你的電腦上辨識，聲音不會上傳；只有按住時麥克風才會開啟。

    五分鐘，把順打會的事都玩一遍。每一步都是在框裡真的打字：對了就自動到下一步；想複習哪個功能，點章節就好。
    
        
    
          
    
          
          
        
    
        
    
        
    全部走完了。之後想複習，系統匣圖示按右鍵 →「練習場…」就回得來。
    
        
    練習時輸入法不會學習、不會動你的詞庫。一打就對的那一步（你的詞庫已經會了）直接送出也算過。
    
        
    
      
    

      
      
    
        
    資料與隱私
    
        
    你的設定和學到的詞都存在這台電腦，不會上傳。可以匯出帶到另一台電腦。
    
        
    
          
    我的記憶
    
          
    
            
    資料位置
    （設定、詞庫、學習紀錄、紀錄檔）
    
            
          
    
          
    
            
    記憶大小

    一萬個詞約 1–2 MB。只用過一次、超過 4 個月沒再用的學習紀錄會自動清掉；自己加的詞和封鎖的詞不會。「立即整理」還會清掉以前誤學、不是詞的兩字組（像「開新」）。
    
            
          
    
        
    
        
    
          
    搬到另一台電腦
    
          
    
            
    匯出我的記憶
    產生一個「我的記憶.smartime」檔案，包含設定、我的詞庫（含分類）、學習紀錄和封鎖的詞。
    
            匯出…
          
    
          
    
            
    匯入我的記憶
    選另一台電腦匯出的檔案。只會合併，不會蓋掉現有的東西：沒有的加進來，兩邊都有的詞次數相加。可以匯入好幾台的檔案，重複匯入也不會重複計算。
    
              
    
            
            
          
    
        
    
        
    
          
    清除與重設
    
          
    
            
    清除學習紀錄
    只清掉自動學到的，自己加的詞會保留。
    
            
    
          
    
          
    
            
    所有設定恢復預設值
    詞庫不受影響。
    
            
    
          
    
        
    
        
    
          
    除錯紀錄 目前開啟
    
          
    
            
    PIME 除錯紀錄
    把每個按鍵寫進 ，用來找問題；平常請關閉。切換時輸入法會重新啟動一次。
